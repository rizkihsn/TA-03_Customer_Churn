# Prediksi Customer Churn

Aplikasi web untuk memprediksi risiko pelanggan berhenti berlangganan menggunakan algoritma Logistic Regression.

## Dataset
Telco Customer Churn

Sumber: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Teknologi
- Python
- Pandas
- Scikit-learn
- Flask
- Joblib
- HTML dan CSS

## Fitur
- Input data pelanggan
- Prediksi risiko customer churn
- Menampilkan probabilitas churn

## Cara Menjalankan
1. Install dependensi:
   `py -m pip install -r requirements.txt`

2. Jalankan aplikasi:
   `py app.py`

3. Buka browser:
   http://127.0.0.1:5000/

## Algoritma
Logistic Regression

## Evaluasi Model
- Akurasi: 72,49%
- ROC-AUC: 0,8344
- Recall churn: 80%
